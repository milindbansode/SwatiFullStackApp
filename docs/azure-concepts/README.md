# Azure Concepts

This folder keeps Azure topics separate so cloud learning can grow independently from the main roadmap.

## Covered topics

1. **Azure App Service** - host ASP.NET Core APIs quickly with staging slots and autoscale.
2. **Azure Functions** - run event-driven jobs without keeping full servers online.
3. **Azure Container Apps / AKS** - use containers when portability and advanced scaling matter.
4. **Azure SQL Database** - keep transactional business data in a managed relational store.
5. **Azure Storage** - store blobs such as reports, screenshots, and uploaded documents.
6. **Azure Service Bus** - decouple services using durable queues and topics.
7. **Azure Key Vault** - keep secrets, keys, and certificates outside code.
8. **Application Insights** - monitor requests, failures, and performance trends.
9. **Azure DevOps / GitHub Actions** - automate build, test, security, and release flow.

## Practical usage

Use this folder when you want to turn the learning app into a deployable cloud reference project. Each topic already appears in the API and Angular UI, so you can extend the notes with architecture diagrams, IaC examples, and deployment walkthroughs later.
